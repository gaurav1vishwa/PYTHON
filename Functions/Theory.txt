    DIFFERENCE TYPE OF FUNCTIONS

1. NO ARGUMENTS AND NO RETURN VALUE
def greet():
    print("Hello!")

2. NO ARGUMENTS BUT RETURN VALUE
def get_greeting():
    return "Hello!"

3. ARGUMENTS BUT NO RETURN VALUE
def greet_user(name):
    print(f"Hello, {name}!")

4. ARGUMENTS AND RETURN VALUE
def get_user_info(name, age):
    return f"{name} is {age} years old."
